# Employee Operating Guide
Document: OPS-PL-001 | Version 1 | Effective: 14 November 2026
Meridian Bank | Personal lending

## 7.1 Reviewing an application
Open Applications and search by name, application ID, mobile or account ID. Select the application. Run eligibility checks, review the Assessment findings, inspect original evidence in Documents and read the Timeline before recording a decision.

Missing bank statements can be supplied using Add statement in the document register. This makes the prepared sample statement available for that application and invalidates its earlier assessment. Run checks again before deciding.

## 7.2 Recording a decision
A credit officer records approval, decline or a request for information with a reason. Approval requires a current assessment and no pending mandatory evidence or decline recommendation. For manual-review findings, record an exception justification if approving. The assistant may navigate or run checks; it cannot record final decisions.

## 7.3 Sanction and disbursement
After approval, issue sanction. Record customer acceptance, the completed agreement and repayment mandate. These conditions must be met before the employee confirms disbursement. No real funds move in this assignment.

## 7.4 Changing policy
Policy admins edit, validate and submit draft rules. A Policy reviewer activates the version. Existing assessments retain the earlier snapshot and need reassessment. Configured rules and approved source documents are separate records: changing a rule does not rewrite a policy PDF. If there is no approved source file for the active version, the assistant must say it cannot substantiate that version from documents.

## 7.5 Evidence map
The evidence map displays known links between an application, original documents, recorded facts, assessment checks and cited policy clauses. These links are assembled from document metadata and the rules engine. They are not relationships inferred automatically from arbitrary document prose. The assistant uses vector retrieval; the evidence map is not GraphRAG.

## 7.6 Environment
All customer data and identity/bureau responses are synthetic. Workspace roles are simulated. Workflow state is saved in the browser; source files and the retrieval index are stored on the local server. Never use real customer documents in this assignment.
